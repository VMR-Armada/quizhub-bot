# QuizHub

Телеграм-бот с расписанием барных квизов. Ищет игры по городу, дню и теме, ведёт подписки, принимает объявления «ищу команду / игрока» и показывает таблицу на сайте.

Логика похожа на [@quiztodaybot](https://t.me/quiztodaybot): свободный запрос в чате, деление на день и вечер, темы вроде «ким», командное расписание и персональная таблица. Это отдельный бот со своим каталогом. Чужое расписание он не забирает. При первом запуске в базе лежат вымышленные игры, чтобы поиск сразу было на чем проверить. Свои игры добавляет администратор командой `/newquiz`.

Нужен Python 3.12. Бот написан на [aiogram](https://docs.aiogram.dev/), таблица отдаётся через aiohttp, данные лежат в SQLite.

## Запуск

1. В Telegram откройте [@BotFather](https://t.me/BotFather), команда `/newbot`, скопируйте токен.
2. Узнайте свой числовой id: его напишет этот бот в ответ на `/help`.

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

macOS и Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

В `.env` вставьте токен и свой id:

```
BOT_TOKEN=123456:токен
ADMIN_IDS=123456789
```

Запуск:

```bash
python bot.py
```

Бот начнёт принимать сообщения, а таблица откроется на http://127.0.0.1:8080

Файл `.env` и база `data/*.db` в git не попадают. В репозитории лежит только `.env.example` с пустым шаблоном.

## Как пользоваться

В личке можно писать обычным языком:

- `сегодня`
- `завтра вечером`
- `суббота музыка`
- `выходные рок`
- `18.10 кино`
- `москва гарри поттер`
- `ким` — игры, где одновременно есть кино и музыка

День — всё, что начинается до 18:00. Вечер — с 18:00.

| Команда | Что делает |
|---|---|
| `/city` | Запоминает город |
| `/today`, `/tomorrow` | Квизы на день |
| `/sub музыка` | Подписка: бот пришлёт новую игру по теме |
| `/table` | Ссылка на таблицу и на персональный фильтр организаторов |
| `/find` | Объявление «ищу игрока» или «ищу команду» |
| `/createschedule` | В чате команды публикует расписание на 7 дней |
| `/newquiz` | Добавить игру (только id из `ADMIN_IDS`) |
| `/cancel` | Прервать текущий шаг |

В группе бот отвечает на команды и на упоминание: `@имя_бота завтра вечером`.
